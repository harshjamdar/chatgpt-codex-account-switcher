OPENAI PROFILES 5.1 - TEST REPORT
Tested: 20 November 2026
Native package tested: OpenAI.Codex 26.1117.3838.0

RESULT: 88 checks passed across the four suites below.
Final release checks also passed: native installation lookup, 125-profile
persistence self-test, live-session launch guard, and exact setup payload hash.
The backend integration was rerun after RPC changes (9 overlapping checks passed).

FIXES
- Ignore orphan native worker processes as account sessions. Infer profile
  ownership from descendants when native relaunch drops the root arguments.
- Bound native-install lookup and signature helper waits; detect exited RPC
  helpers promptly and handle interactive callbacks explicitly.
- Invalidate stale displayed account identity after credential-file changes.
- Compare sampled chat IDs and metadata; paginate beyond 100 project results;
  count only the newest state schema instead of adding obsolete schemas.
- Preserve committed WAL data and recover every touched file if restore fails.
  Reject mismatched-source, legacy-unscoped and tampered snapshots.
- Prevent colliding shortcut names from opening the wrong account. Preserve
  stable IDs and custom store arguments. Suppress launch clicks after dragging.
- Handle occupied global hotkeys and initialize/dispose tray resources once.
- Atomically save installer metadata and retry transient profile-file locks.

TEST SCOPE AND LIMITS
All test stores were isolated. No real company sign-in or model request was
performed, and no live shared history was restored. Native GUI A/B/A tests used
signed-out profiles. Backend A/B/A tests used synthetic API credentials with a
loopback-only provider and verified actual shared chat read/resume behavior.
Existing user app processes were retained throughout.
The production guard correctly refused opening another profile while the user's
app was active. Full switching between authenticated company accounts and SSO
must still be checked manually after quitting the current native app.
Cloud ChatGPT Projects/chats are account-bound; local SQLite sharing does not
merge those cloud accounts or change company permissions.
No signing certificate/HTTPS release host was available. Unsigned/unconfigured
update rejection was tested; trusted download success was not tested.
UI tests exercised dialogs, handlers, rendering, queue/cancel and hotkey routing;
they do not prove every physical mouse/keyboard gesture on every display.
